# Decentralized First-Order Methods under Hölder Continuous Gradients

Code and raw results for the paper

> Y. Song, *Decentralized First-Order Methods under Hölder Continuous Gradients: A Numerical Study on a Reaction-Diffusion Equation and Multi-Slice Sparse Reconstruction*, submitted to *Algorithms* (MDPI).

## Contents

| Path | What it holds |
|---|---|
| `code/` | solvers, experiment scripts, `make_figures.py`, `make_tables.py`, `run_all.sh` |
| `results/` | raw output of every run (`.json`, `.npz`, `.log`) and the generated LaTeX tables in `results/tables/` |
| `figures/` | Figures 1 to 7 as they appear in the paper |

Appendix A of the paper lists the script behind each table and figure.

## Reproducing the results

```bash
pip install -r requirements.txt
cd code
python get_template.py      # copies the ICBM 2009a T1 template from nilearn into code/data/
bash run_all.sh             # all experiments, then make_figures.py and make_tables.py
```

All runs are single-threaded NumPy with fixed seeds. The full sequence takes about two hours on two cores. To regenerate the figures and tables from the stored results only:

```bash
cd code
python make_figures.py
python make_tables.py
```

## Data

The synthetic phantoms and the reaction-diffusion problems are generated by the scripts. The real-anatomy experiment (Section 3.2.5) uses the ICBM 2009a nonlinear symmetric T1 template (Fonov et al., NeuroImage 2009 and 2011), McConnell Brain Imaging Centre, in the version distributed with nilearn. It is not redistributed here; `code/get_template.py` copies it from an installed nilearn.
